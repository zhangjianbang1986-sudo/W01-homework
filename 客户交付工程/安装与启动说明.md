## 最少启动动作

1. 在 Finder 中双击 [`启动FDE产品.command`](%E5%90%AF%E5%8A%A8FDE%E4%BA%A7%E5%93%81.command)。
2. 若使用 DeepSeek 官方服务，前三项直接按回车，保留默认值：
   - 地址：`https://api.deepseek.com/chat/completions`
   - 模型：`deepseek-flash`
   - 请求配置：`deepseek-low`
3. 在终端提示处粘贴自己的 DeepSeek API Key。输入不会显示，按回车继续。
4. 看到启动地址后，在浏览器打开 `http://127.0.0.1:8765`。
5. 使用结束后回到终端按 `Control+C` 停止服务。

如果实际购买的是中转或第三方兼容服务，需要把前三项改成该服务商提供的完整 Chat Completions HTTPS 地址、模型名和兼容的请求配置。不要把官方地址与中转密钥混用，也不要在聊天中发送密钥。

## 安全说明

- 启动脚本只在终端内隐式读取密钥，并作为本次进程环境变量使用；不会写入工程文件或 `.env`。
- 工程已忽略 `.env`、`.env.*`、`*.key`、`*.pem`、`.venv/` 和 `.runtime/`，降低误提交风险。
- 课程程序只绑定本机 `127.0.0.1`。产品页面默认端口为 `8765`，标签 Mock 使用启动时显示的随机端口。
- 不要在截图、聊天、作业附件或终端命令中展示 API Key。

## 常用维护命令

以下命令均在当前工程目录执行，平时使用双击入口即可，不要求用户手动操作：

```sh
.venv/bin/python tools/check_product.py --dry-run
.venv/bin/python -m pytest tests/test_product_v2.py tests/test_product_interaction.py tests/test_model_policy.py
```

运行状态保存在 `.runtime/product/`。课程说明建议需要全新演示状态时使用新的 `--home` 目录，不直接删除旧证据。
